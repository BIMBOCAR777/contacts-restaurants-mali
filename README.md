# Contacts restaurants – Mali

Page pour enregistrer d'un coup sur son téléphone les 10 restaurants de la liste de prospection qui ont un numéro.

- `index.html` : la page (boutons Enregistrer, Appeler, WhatsApp)
- `restaurants-mali.vcf` : tous les contacts en un seul fichier
- `vcf/<n°>.vcf` : un fichier par restaurant
